# AI Learning Map UI rationale

- **Color:** deep slate keeps the long reading experience calm; cyan marks learning progression, violet marks increasing system complexity, and emerald is reserved for production constraints.
- **Layout:** the page follows the learning journey from map to detail to systems practice, so readers see the dependency before the reference material.
- **Typography:** the interface uses a readable system sans for explanations and compact monospace labels only for stages, tags, and technical metadata.
- **Spacing:** wide section gaps separate learning modes, while tighter card spacing keeps related educational material together.
- **Surfaces:** restrained translucent panels distinguish reading units without making every element appear elevated.
- **Icons:** each icon names a learning-system function (model, data, compute, retrieval, tool, network) rather than acting as decoration.
- **Motion:** only native smooth navigation and short state transitions are used to preserve orientation; the reduced-motion preference disables them.
